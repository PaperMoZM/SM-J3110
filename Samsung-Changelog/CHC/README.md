# Samsung Galaxy J3 Pro SM-J3110 CHC changelog archive

This folder contains an offline, self-contained transcription of the update history visible on Samsung's official device page:

- Source: https://doc.samsungmobile.com/SM-J3110/CHC/doc.html
- Device / region: Galaxy J3 Pro (SM-J3110), CHC (China)
- Captured: 2026-10-14 (Asia/Shanghai)
- The archived view contains the six update entries shown by the official page, with the three available language choices: English, Korean, and Simplified Chinese.
- Open `index.html` directly in a browser. Language switching works offline; no external scripts, stylesheets, fonts, or images are required.

## Capture notes and limits

The official page loaded successfully in the browser. Its outer page is titled “Notify Update” and presents a single language selector (`sel_lang`) with English, Korean, and Simplified Chinese. Changing the selector replaced the embedded document URL and its content:

- Simplified Chinese: `/SM-J3110/000022170406/zho-cn.html?timestamp=…`
- English: `/SM-J3110/000022170406/eng.html?timestamp=…`
- Korean: `/SM-J3110/000022170406/kor.html?timestamp=…`

The timestamp changed at each selection. Each language showed the same six build numbers and release dates. The original site's source HTML, linked CSS/JavaScript/image files, and browser Network request log could not be retrieved in this environment: direct HTTP retrieval failed with an authentication/network error, and the browser security policy blocked opening a `view-source:` URL. Therefore this is a faithful text/content snapshot of what the official page rendered in those three selectable languages, not a byte-for-byte mirror of Samsung's original page or a verified capture of every hidden request/resource. No original graphics or assets were visible in the rendered content captured here.
