# Samsung Galaxy J3 Pro (SM-J3110)

A collection of firmware, images, custom ROMs, and other resources for the Samsung Galaxy J3 Pro (SM-J3110).

This repository is intended to collect, archive, and preserve useful files and resources related to the SM-J3110.

## Contents

This repository contains:

- Official Samsung firmware for the SM-J3110
- Extracted stock `boot.img` and `recovery.img`
- Magisk-patched boot images for root
- Unofficial TWRP builds collected from third-party sources
- Unofficial LineageOS builds and related resources
- Other files and notes related to modding and development for the SM-J3110

Additional files, tools, builds, and other resources related to the SM-J3110 may also be added to this repository over time, even if they are not explicitly listed above.
